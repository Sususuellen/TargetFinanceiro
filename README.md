# 🎯 Target — Gestão de Metas Financeiras

> Aplicativo mobile para criação e acompanhamento de metas financeiras, permitindo ao usuário definir objetivos, registrar aportes e acompanhar o progresso de forma simples e intuitiva.

---

## 🚀 Sobre o Projeto

O **Target** é um aplicativo de gestão de metas financeiras no qual o usuário pode criar objetivos (como viagens, compras ou reservas financeiras), acompanhar quanto já foi economizado, quanto ainda falta e registrar movimentações de entrada e saída de valores.

---

## 🎯 Funcionalidades

- ✔ Criação de metas financeiras
- ✔ Listagem de metas cadastradas
- ✔ Visualização de progresso de cada meta
- ✔ Registro de aportes (guardar dinheiro)
- ✔ Registro de resgates (retirar dinheiro)
- ✔ Cálculo automático de saldo e progresso
- ✔ Acompanhamento visual do objetivo

---

## 🧠 Conceitos Abordados

- Estruturação de aplicações mobile
- Componentização em React Native
- Gerenciamento de estado com React Hooks
- Persistência de dados local (AsyncStorage)
- Navegação entre telas
- Lógica de controle financeiro
- Atualização imutável de dados

## 💾 Armazenamento de Dados

Os dados são armazenados localmente utilizando **AsyncStorage**, garantindo:

- Persistência das metas
- Atualização de valores em tempo real
- Consistência entre sessões do app

---

## 📊 Lógica Financeira

Cada meta possui:

- Valor total desejado
- Valor atual acumulado
- Cálculo automático de progresso (%)
- Registro de transações (entrada e saída)
